# Python: EDA + Satisfaction Prediction

- Exploratory data analysis on ticket priority, channel, resolution time, 
  and satisfaction distributions (pandas, matplotlib/seaborn)
- A classification model (scikit-learn) predicting whether a ticket will 
  receive a low satisfaction rating, based on priority, channel, and ticket 
  type, evaluated with a confusion matrix and precision/recall

See `eda_and_satisfaction_model.ipynb`.
