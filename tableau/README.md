# Support Analytics Dashboard (ticket_dashboard)

An interactive Tableau dashboard analyzing resolution time by priotiy (excluding negative 
handling times). satisfaction by channel, ticket volume by product. and priority by ticket 
type in a single dashboard with the oprion to view each sheets individually.

**[View live on Tableau Public](https://public.tableau.com/views/ticket_dashboard/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)**
